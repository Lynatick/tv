# horizon tv

Лёгкий домашний экран только для Android TV и Google TV (Android 8.0+).

Скачать: https://lynatick.github.io/tv/
Исходники: https://github.com/Lynatick/tv

## Возможности

- Выбор приложений, отображаемых на главном экране. Порядок карточек можно менять.
- При возврате домой фокус сразу на последнем выбранном приложении или на первой избранной карточке.
- Значок ↓ вверху появляется при наличии обновления Horizon TV: скачивание APK, проверка SHA-256 и системная установка с подтверждением.
- Все запускаемые приложения в отдельном разделе, включая установленные вручную.
- Текущее системное время, дата, 12/24 часа, отображение секунд.
- Meteoblue рядом с часами на общем фоне рабочего стола: прогноз по 3 часа только на сегодня и на 7 дней. Кнопки «День», «Неделя», «Город», «Развернуть» и «↻ Обновить» доступны с пульта. Высота блока ограничена: длинный прогноз прокручивается внутри и не сдвигает приложения.
- Анапа по умолчанию; ранее выбранный город сохраняется.
- Автоматический город по внешнему IP через ipwho.is или поиск города вручную через Open-Meteo / GeoNames.
- Интервалы перезагрузки страницы погоды: 15, 30, 60, 120, 360 минут или только вручную.
- Три темы, 4/5/6 карточек в строке, скрытие названий и виджета погоды.
- Быстрый доступ к сети, Bluetooth, звуку, изображению, приложениям и времени ТВ.
- Выбор Horizon TV в качестве системного домашнего экрана, если прошивка разрешает смену лаунчера.
- Управление пультом, сохранение настроек. Без собственной рекламы и аналитики; информер Meteoblue работает по правилам поставщика.

## Установка

1. Скачайте `horizon-tv-1.0.5.apk` и перенесите его на телевизор.
2. Откройте APK файловым менеджером. При запросе Android разрешите установку из этого источника.
3. Запустите **Horizon TV** в списке приложений телевизора.
4. Откройте «Настройки → Сделать главным экраном» и подтвердите выбор в системном окне.
5. На главном экране нажмите «Выбрать» для выбора приложений и «Город» для настройки погоды.

На некоторых Google TV и телевизорах производителей смена домашнего приложения ограничена. В этом случае Horizon TV можно запускать из списка приложений. Приложение не отключает заводской лаунчер и не требует root/ADB для обычного использования. Для возврата выберите заводской домашний экран в системных настройках или удалите Horizon TV.

## Mi TV Stick 4K: главный экран без ADB

Откройте «Настройки → Сделать главным экраном». Доступны два режима:

1. **Системный выбор.** Нажмите «Сделать главным экраном» и подтвердите выбор Horizon TV с пульта. После успешного назначения приложение показывает его основным лаунчером.
2. **Возврат по кнопке Домой.** Если прошивка продолжает запускать штатный экран, нажмите «Кнопка Домой на Mi TV Stick 4K» и в системных «Специальных возможностях» включите «Horizon TV: кнопка Домой». Для установленных из APK приложений Android может сначала потребовать разрешить ограниченные настройки в сведениях о приложении.

Второй режим — служба специальных возможностей, которая возвращает в Horizon TV при появлении штатного лаунчера, включая запуск после загрузки системы. Он не меняет системного владельца роли HOME и не отключает заводской лаунчер. Служба получает только события `TYPE_WINDOW_STATE_CHANGED` для пакетов домашних экранов и проверяет название Activity. Доступ к содержимому окон, тексту, паролям, клавишам и скриншотам не запрашивается. Служба включается пользователем и отключается в том же разделе настроек. Компьютер, ADB и root для обоих режимов не требуются.

На некоторых прошивках оба механизма могут быть ограничены производителем. Физический Mi TV Stick 4K не подключён; работоспособность на конкретной прошивке Xiaomi пока не подтверждена. На эмуляторе Android TV 14 системная роль HOME назначается, но штатный лаунчер с приоритетом 2 продолжает открываться: именно для такого случая предусмотрена дополнительная служба.

## Обновление приложения

Новые стабильные версии проверяются через сайт lynatick.github.io/tv/ при открытом приложении не чаще раза в 6 часов. При ошибке повторная попытка — через 15 минут; в фоне проверки не выполняются. В «Настройки → Обновление Horizon TV» можно проверить вручную. Сайт скачивания получает IP подключения, данные о приложениях и погоде ему не отправляются. Значок ↓ появляется только при наличии более новой версии.

Нажмите ↓, скачайте APK и после завершения выберите «Установить обновление». Перед установкой проверяются размер и SHA-256 из страницы скачивания. Android может попросить разрешить Horizon TV установку из этого источника; затем потребуется подтвердить обновление в системном установщике. Установка без подтверждения не выполняется. Настройки сохраняются. При недоступности обновления скачайте APK с https://lynatick.github.io/tv/.

## Пульт

Стрелки — навигация; OK — выбор; удержание OK на приложении — добавление/удаление избранного, перемещение, сведения; MENU — настройки; Назад — закрытие панели/возврат домой. Все функции доступны без сенсорного экрана.

## Meteoblue: день, неделя и город

Рядом с часами встроен официальный [информер Meteoblue](https://business.meteoblue.com/products/plug-and-play-visuals/free-forecast-widget). Используется поддерживаемый поставщиком прозрачный фон со светлым текстом: за прогнозом виден тот же рабочий стол. Прогнозные значения и ссылка на полный прогноз сохраняются. Графический логотип Meteoblue внутри информера скрыт; источник указан текстом в заголовке Horizon TV. Приложение скрывает координаты и дополнительные дни в почасовом режиме, а блок текущих условий делает компактнее. Название города остаётся в заголовке Horizon TV. Погодный блок имеет фиксированную высоту, поэтому длинный прогноз не отодвигает карточки приложений за экран.

- **День** — прогноз по 3 часа только на текущий день. Вкладки других дней скрыты, блок текущих условий уменьшен, поэтому прокрутки меньше. Расписание, температура, ветер и осадки сегодняшнего дня сохраняются.
- **Неделя** — информер на 7 дней с погодными значками, максимальной и минимальной температурой.
- **Город** — поиск по названию или автоматическое определение по внешнему IP.
- **Развернуть / Свернуть** — увеличить прогноз для чтения на телевизоре.
- **↻ Обновить** — повторно загрузить прогноз без кэша WebView. Повторное нажатие доступно через 30 секунд.
- **Обновлено 20.10 14:25** — дата и время последней успешной загрузки информера в часовом поясе телевизора. Это время загрузки, а не выпуска погодной модели. При ошибке оно не меняется; рядом появляется сообщение о сбое. После смены города или пересоздания блока время появится после новой успешной загрузки.

Стрелки пульта перемещают фокус и прокручивают прогноз. Стрелка вверх в начале страницы возвращает фокус к кнопкам блока. «Назад» сначала выходит из веб-страницы к кнопкам, следующее нажатие возвращает на главный экран. При возврате домой фокус на приложении сохраняется.

Город, период и интервал сохраняются; при обновлении сохраняется ранее выбранный период. Поддерживаются интервалы 15, 30, 60, 120, 360 минут и «Только вручную». Интервал задаёт повторную загрузку информера; актуальностью своих данных управляет Meteoblue. При скрытом блоке загрузка и таймеры WebView приостанавливаются. Нужен включённый Android System WebView. Публичный 3-часовой информер Meteoblue возвращает минимум четыре дня даже при `days=1`. Компактное отображение применяется из встроенного `meteoblue-presentation.js`: дополнительные дни и координаты скрываются стилями, прогнозные значения не извлекаются и не пересчитываются. Если формат страницы поставщика изменится и компактный режим нельзя применить, приложение покажет сообщение об ошибке без изменения времени последней успешной загрузки. API-ключ в приложении не используется; доступность публичного информера зависит от правил поставщика и сети телевизора.

По умолчанию выбрана Анапа (44.89497, 37.31623). При обновлении ранее выбранный город сохраняется; значение по умолчанию применяется только когда город ещё не настроен. Автоматический режим обращается к `https://ipwho.is/`; при VPN может определиться город сервера. Поиск отправляет название в Open-Meteo Geocoding / GeoNames. Координаты выбранного места передаются Meteoblue по HTTPS для выбора прогноза. Координаты и высота над уровнем моря внутри информера скрыты; название города видно в заголовке Horizon TV.

Сохраняются ссылки на прогноз Meteoblue; источник указан в заголовке Horizon TV. Информер может использовать cookies и аналитику поставщика либо потребовать проверку подключения. Horizon TV не обходит такие проверки. Сторонние cookies запрещены; доступ к локальным файлам, содержимому устройства, микрофону, камере и геолокации не предоставляется. JavaScript-мост не используется. Встроенная навигация ограничена погодными HTTPS-страницами Meteoblue.

Настройки и избранное хранятся на телевизоре, резервное копирование отключено. Источники: [Meteoblue](https://www.meteoblue.com/), [поиск городов Open-Meteo](https://open-meteo.com/en/docs/geocoding-api), [GeoNames](https://www.geonames.org/), [ipwho.is](https://ipwho.is/). Условия и внешний вид информера определяет Meteoblue; см. [конструктор](https://www.meteoblue.com/en/weather/widget/setupday/moscow_russia_524901).

## Сборка

Используется **JDK 25**, Gradle 9.1.0, Android Gradle Plugin 9.0.1, Android SDK 36. Байткод Java 17 для совместимости Android; сама сборка выполняется Java 25. Зависимостей времени выполнения вне Android Framework нет.

```sh
export JAVA_HOME=/path/to/jdk-25
export ANDROID_HOME=/path/to/android-sdk
./gradlew :app:testDebugUnitTest :app:lintRelease :app:assembleRelease
```

На машине разработчика: `zsh build.sh :app:testDebugUnitTest :app:lintRelease :app:assembleRelease --offline`.
`python3 tools/package.py` создаёт/использует отдельный локальный ключ `signing/`, проверяет и подписывает выпуск, создаёт исходный ZIP и SHA-256. `signing/`, `local.properties`, кэши и секреты исключены из Git и ZIP. Сохраните локальный ключ для подписания следующих обновлений.

Проверка компактного представления на живых страницах: `HORIZON_PLAYWRIGHT=/path/to/playwright node tools/meteoblue-presentation-qa.cjs` (нужны Playwright и Google Chrome). Проверяет один сегодняшний день, сохранность погодных значений и ссылки на полный прогноз, отсутствие координат и графического логотипа и обработку изменения структуры страницы.

Значок создан встроенным ImageGen. Промпт и исходное изображение сохранены в `ICON.md` и `icon-original.png`.
