# horizon tv 1.0.5

- Режим «День» показывает прогноз Meteoblue по 3 часа только на сегодня. Вкладки других дней скрыты, блок текущих условий уменьшен — прокрутки меньше.
- Убраны заголовок «Погода» с координатами, строка координат и высоты внутри информера. Название города остаётся в заголовке Horizon TV.
- Графический логотип Meteoblue и подпись A Windy.com Company внутри информера скрыты. Источник указан текстом в заголовке Horizon TV.
- Погодные значения и ссылка на полный прогноз сохранены. Недельный прогноз по-прежнему содержит 7 дней.
- Сохранены прозрачный фон, Анапа по умолчанию, ручное обновление и время успешной загрузки. Положение приложений не меняется.
- При недоступности страницы или изменении формата информера показывается сообщение об ошибке, время обновления не меняется.

Скачать: https://lynatick.github.io/tv/

APK подписан прежним ключом, настройки сохраняются. Установка на физический ТВ не выполнялась.
