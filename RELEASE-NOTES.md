# horizon tv 1.0.4

- Meteoblue вместо Яндекса: официальный прозрачный информер рядом с часами, на общем фоне рабочего стола.
- «День» — прогноз по 3 часа; «Неделя» — 7 дней. Сохранены выбор города, автоматическое определение по IP, разворачивание и интервал обновления.
- Анапа установлена по умолчанию; ранее выбранный пользователем город сохраняется.
- Кнопка «↻ Обновить» для ручной загрузки. Под прогнозом — дата и время последней успешной загрузки; при ошибке прежнее время сохраняется. Это не время выпуска погодной модели.
- Погодный блок ограничен по высоте: длинный прогноз прокручивается внутри и не сдвигает ряд приложений вниз. Фокус на приложении при возврате домой сохранён.
- Для работы нужен Android System WebView. Ссылки и атрибуция Meteoblue сохранены; доступность информера зависит от поставщика и сети ТВ.

Скачать: https://lynatick.github.io/tv/

APK подписан прежним ключом; избранное и настройки сохраняются. `SHA256SUMS.txt` содержит контрольные суммы APK и ZIP исходников. Установка на физический ТВ в рамках этого обновления не выполняется.
