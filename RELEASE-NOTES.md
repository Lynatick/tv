# horizon tv 1.0.2

- При возврате на главный экран фокус сразу переходит на последнее выбранное приложение. Если оно недоступно, выбирается первая избранная карточка; при пустом избранном — добавление приложений.
- В верхней панели появляется значок ↓, когда доступна новая стабильная версия Horizon TV. Проверка выполняется через сайт скачивания раз в 6 часов, пока экран открыт; ручная проверка — в настройках.
- Обновление можно скачать с пульта. Перед установкой проверяются размер и SHA-256 APK, затем Android запрашивает подтверждение установки. Настройки сохраняются.

Скачать: https://lynatick.github.io/tv/

APK подписан тем же локальным ключом, что и 1.0.0. `SHA256SUMS.txt` содержит контрольные суммы APK и ZIP исходников.

Проверка версии использует сайт скачивания и не зависит от лимита GitHub API.
