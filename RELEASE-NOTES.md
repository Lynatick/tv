# horizon tv 1.0.3

- На главном экране только Яндекс Погода: встроенная оригинальная страница без API-ключа.
- Кнопки «День», «Неделя», «Город» и «Развернуть / Свернуть» управляются с пульта.
- Выбранные город, период и интервал перезагрузки сохраняются. Поиск города и определение по внешнему IP сохранены.
- Другие погодные источники и ввод API-ключей убраны из интерфейса. Прогноз отображается без изменения содержимого страницы Яндекса.
- При скрытом блоке WebView приостанавливается. Для работы нужен Android System WebView; страница Яндекса может содержать рекламу, cookies или проверку подключения.

Скачать: https://lynatick.github.io/tv/

APK подписан прежним ключом; избранное и настройки сохраняются. `SHA256SUMS.txt` содержит контрольные суммы APK и ZIP исходников. Установка на ТВ в рамках этого обновления не выполняется.
